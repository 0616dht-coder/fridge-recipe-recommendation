냉장고 기반 맞춤 레시피 추천 앱

[포함 기능]
- 냉장고 재료 추가, 수정, 삭제
- 주재료와 양념·조미료 분류
- 소비기한 반영
- 영양 및 음식 종류 조건 추천
- 유튜브 및 네이버 검색
- 좋아요와 관심 없음 기록
- 피드백 기반 개인화 재정렬

[Streamlit Community Cloud 배포 순서]
1. 이 ZIP의 압축을 풉니다.
2. 압축을 푼 파일 6개를 GitHub 저장소의 최상위 폴더에 업로드합니다.
3. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
4. Create app을 누르고 GitHub 저장소와 main 브랜치를 선택합니다.
5. Main file path를 app.py로 지정한 뒤 Deploy를 누릅니다.

[주의]
- ZIP 파일 자체가 아니라 압축을 푼 파일들을 GitHub에 올려야 합니다.
- 배포 서버가 재시작되면 냉장고와 피드백 데이터가 초기 파일 상태로 돌아갈 수 있습니다.
- 이 버전의 피드백 로그는 0건으로 초기화되어 있습니다.
